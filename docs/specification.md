# UNITS
<p>```ξ = x/a```,  ```κ = ka```,  ```τ = t/T```  with  ```T = m a²/ħ```</p>
<p>```ψ(ξ,τ) = 1/(π√2) ∫ (sin κ/κ) · exp[i(κξ − κ²τ/2)] dκ```,  integrand → 1 at ```κ = 0```</p>
<p>Box edges at ```ξ = ±1```. ```ψ``` is dimensionless; ```|ψ|²``` is probability per unit ```ξ```.</p>
<p>Convert to SI only at the end:  ```x = aξ```,  ```t = Tτ```,  ```Ψ = ψ/√a```</p>
