# UNITS
```ξ = x/a```,  ```κ = ka```,  ```τ = t/T```  with  ```T = m a²/ħ```
```ψ(ξ,τ) = 1/(π√2) ∫ (sin κ/κ) · exp[i(κξ − κ²τ/2)] dκ```,  integrand → 1 at ```κ = 0```
Box edges at ```ξ = ±1```. ```ψ``` is dimensionless; ```|ψ|²``` is probability per unit ```ξ```.
Convert to SI only at the end:  ```x = aξ```,  ```t = Tτ```,  ```Ψ = ψ/√a```
